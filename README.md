# 칸반 보드 생성 - 컴포넌트

## 1단계 - 칸반 보드 생성(상품 목록) 구현할 기능 목록

### 새 태스크 생성 모달 구현

- [x] 제목을 필수로 입력 받는다.
    - [x] 제목을 입력하지 않으면 에러 문구를 출력한다.
- [x] 설명을 입력 받는다.
- [ ] 태그를 쉼표로 구분하여 입력 받는다.
    - [ ] 형식에 맞지 않으면 에러 문구를 출력한다. 
    - [ ] 태그가 5자 이내가 아니라면 에러 문구를 출력한다.
    - [ ] 태그가 5개를 초과하면 에러 문구를 출력한다.
- [ ] 태스크 상태로 3가지(To Do, In Progress, Done)를 가진다.
    - [ ] 첫 번째 요소가 기본으로 선택된다.
    - [ ] 한 항목만 선택 가능하다.
- [ ] 담당자를 필수로 입력 받는다. 
    - [ ] 첫 번째 요소가 기본으로 선택된다.
    - [ ] 한 항목만 선택 가능하다.
- [ ] 생성 버튼을 누르면 태스크를 생성한다.
    - [ ] 유효한 값이 들어오지 않으면 생성 버튼을 누를 수 없다.
- [ ] x 버튼을 누르면 태스크 생성 모달이 사라진다.
- [ ] 취소 버튼을 누르면 태스크가 생성되지 않고 모달이 사라진다.
- [ ] 피그마에 맞게 디자인을 적용한다.
